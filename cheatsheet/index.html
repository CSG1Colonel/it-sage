Lists

Unordered List

  • Bullet Points
  • "ul" tag is unordered list
  • "ol" tag is ordered list

Ordered List

  1. Numbered List
  2. "ul" tag is unordered list
  3. "ol" tag is ordered list

By the way

  1. Use "start=" attribute to change list count start

Definition List

"DT" (Definition Term)
The tag used for a DL (Definition List) list item
"dd" is the tag for a list description/definition
Definition List quirks
Doesn't have a list character, such as a bullet or number
Otherwise similar to nesting other kinds of lists

Hyperlinks

  • Absolute Link (a href="https://")
    1. Needs "href='(link)'" attribute"
    2. "target= '_blank'" attribute opens link in new tab automatically
  • Relative Link
    1. Links to relative location
    2. "../" can navigate to higher-tier folders
  • Anchor Link
    1. Navigates to elements with ID (use href="#ID")
    2. Use "#top" to navigate to top
  • Email Link
    1. Navigates to local email
    2. Rarely used

Forms

- "form" tags require "action" (i.e. processing-script.php) and "method" (get/post) attributes

- "legend" and "input" tags are nexted inside "fieldset" tag, nested inside "form" tag

- "legend" labels form box

- "input" is self-closing; enables input (use type="text", type="password", type="date", or similar attribute)

- ALL input elements should have type, ID, and name attributes

- Use "for" attribute with labels to tie to inputs

- "textarea" is not a self-closing input
